# Preferences

## Standing assumptions

- Routing: Transitous (keyless, open source and non-commercial use). Digitransit is not an option
  (no key). Why: the user cannot register for a Digitransit key.
- Indoor and station data: OpenStreetMap only; no mall map data (Visioglobe, Mappedin) without a
  licence. Why: the user chose OSM-only on 2026-11-24 and believes OSM can beat paid platforms.
- Exit sign destinations: City of Helsinki station guide PDFs, used only when the parse fits the
  OSM exit letters.
- Stack: Bun, Better-T-Stack scaffold, React, MapLibre, OpenFreeMap tiles; English UI.
- Shipping: commit to `main` in the public repo pnupu/metro-optimizer, then publish
  `apps/web/dist` to Vinssi Pages site 01a20f12-9634-71b9-bf3c-95b9ab38f23d.
